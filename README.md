## 💻 Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/piyush-2807/portfolio.git
```

### 2. Navigate to the project folder

```bash
cd portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Install React Icons

```bash
npm install react-icons
```

### 5. Start the development server

```bash
npm run dev
```

Open the local URL displayed in the terminal. It is usually:

```text
http://localhost:5173/
```

## 📦 Build for Production

Run:

```bash
npm run build
```

The optimized production files will be generated inside the `dist` folder.

## 🌐 Deployment

The portfolio can be deployed using Vercel.

1. Push the project to GitHub.
2. Sign in to Vercel using GitHub.
3. Import the repository.
4. Select the Vite framework preset.
5. Click **Deploy**.

RepRight is an AI-powered real-time exercise posture correction system that helps users perform workouts with proper form.

The application uses TensorFlow.js and MoveNet pose estimation to analyze human body movements through webcam input. It tracks body landmarks, calculates joint angles, provides real-time posture feedback, counts repetitions, and evaluates exercise accuracy.
